# 教學指南（いろどり 入門 A1・五十音）

整理自 2026-10-15 的日文學習交接文件，讓之後在 Claude 或其他地方接手時，用同樣的方式教學和擴充網站。

## 學習者資料

- 台灣人，請一律用**繁體中文**、台灣的說法。
- **完全的日文初學者**。
- 希望照教材**一步一步學**，不要還沒教就先考試。
- 希望用互動網站學習，因為對話裡很多效果（隱藏答案、發音、描字）沒辦法呈現。

## 教學方式

1. **先打好五十音基礎**，再回到課本第 1 課。
2. **每一步只學一行**，學會了才往下。
3. 每一步的講解格式：
   - 一句話說明這一行的規則（例如「k 的子音 ＋ 5 個母音」）。
   - 欄位：**假名｜羅馬拼音｜發音（對照注音）｜來源漢字**。
   - 重點：例外、容易搞混的字、記憶方法。
4. 練習方式：
   - **唸**：每個字大聲唸 5 遍。
   - **寫**：每個字寫 5 次，邊寫邊唸。
   - **唸單字**：只用學過的假名組成的真實單字，先自己唸再看答案。
5. 學習者說「**下一步**」才進入下一步。
6. **不要還沒教就先考試**。測驗只放在學過之後，當作複習或解鎖。
7. 每學完一步，就把新內容加進網站的 `src/data/steps.json`。

## 學習路線

網站目前收錄第 1～42 步：

| 單元 | 步驟 |
|---|---|
| 平假名 | 第 1～10 步（あ行～わ行） |
| 濁音・半濁音 | 第 11～15 步（が ざ だ ば ぱ） |
| 長音・促音・拗音 | 第 16～20 步 |
| 片假名 | 第 21～30 步（ア行～ワ行） |
| 片假名的濁音和小字 | 第 31～33 步 |
| 第1課 おはようございます | 第 34～37 步（見面、道別、謝謝・對不起、貼圖） |
| 第2課 すみません、よくわかりません | 第 38～42 步（請對方再說一次、數字 0～10、會不會日文、日文怎麼說、片假名單字） |

之後每一課照課本的 Can-do 分成幾步，接在後面。下一課：第 3 課 よろしくお願いします。

課本 PDF 和原始音檔放在**私人專案** [xiouyu/learning-japanese-materials](https://github.com/xiouyu/learning-japanese-materials) 的 `A1/`（`FT_X_L01.pdf` 是第 1 課，`mp3/X_[01-02]_*.mp3` 是音檔 01-02），不要放進這個公開專案。做新的一課時，請使用者把私人專案加進對話。課本內容以 PDF 為準；網站用的音檔重新壓成 64 kbps 單聲道、拿掉封面圖片後放在 `public/audio/irodori/A1/Lxx/`；課本句子的步驟用 `"kind": "phrase"`，會話放在 `dialogs`，出處寫在 `source`。
